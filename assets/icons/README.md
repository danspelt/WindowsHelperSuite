# Icon Assets

This folder contains the application icons.

## Required Files

- `app.ico` - Main application icon (multi-resolution ICO with 16x16, 32x32, 48x48, 256x256)
- `app-256.png` - High-res PNG version for README/marketing
- `installer.ico` - Icon for the setup installer

## Icon Design Direction

For the Windows Helper Suite, use:
- Rounded keyboard key shape
- Writing cursor element
- Speech wave element
- Clean blue/teal accent (#60a5fa)
- Strong contrast at small sizes

This represents:
- Writing assistance
- Speech features
- Accessibility
- Helper tools

## Generating Icons

1. Create a 256x256 PNG design
2. Use an icon converter tool (e.g., icoconvert.com or ImageMagick) to create multi-resolution ICO
3. Ensure all sizes are crisp: 16x16, 32x32, 48x48, 128x128, 256x256
